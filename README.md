# lumiabrowser
LumiaBrowser, Electron, React ve Vite ile geliştirilmiş hafif ve modern bir masaüstü tarayıcı projesidir. Google Chrome’a benzer ama daha az sistem tüketir, daha hızlı çalışır ve gizliliğe önem verir. Gereksiz arka plan işlemlerini azaltarak sade ve performanslı bir kullanım deneyimi sunar.
